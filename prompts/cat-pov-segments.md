# Cat POV — Segment Prompts

Copy-ready prompts for **Grok Imagine** (stills) and **Gemini Omni** (short video).  
Treatment: `ideas/cat-pov.md`. Episode 3 animal lock: sleek black cat, yellow eyes. **No dialog. No readable text.**

## Visual arc

Halloween sidewalk at cat height → shed serpents → hay-bale witness → Pizza Guy ankles → crane from fur → dawn residue → optional HOA sill.

## Continuity lock (paste into every still)

Sleek adult black cat, short dense fur, vivid yellow-green eyes, white whiskers, long tail used as a balance pole. Not a kitten. Not fluffy. Not a second cat. Photoreal, cinematic, no cartoon eyes, no collar, no text, no watermark.

Sound (all shots): no spoken lines. Foley only + *Deep Space Drift* pad.
