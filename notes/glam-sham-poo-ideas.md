# Glam-Sham-Poo ideas

Living in-repo dump for the **Glam-Sham-Poo** musical cutaway (videos + songs). Twin of GitHub issue [#32](https://github.com/ford442/weeks_on_fire/issues/32).

Glam-Sham-Poo is both:
- the neon company / region (**Glamora**, Sham-Poo Prefecture)
- a famous college (dorms with better pyro than the chem labs)

## Core assets

- Concept / stills package: [`ideas/glam-sham-poo-commercial.md`](../ideas/glam-sham-poo-commercial.md)
- Minimax track: [`songs/Glam_Sham_Poo_Ultra_Screech.md`](../songs/Glam_Sham_Poo_Ultra_Screech.md)
- Local artifacts (not in repo): stills + `glam_sham_poo_commercial_clip.mp4` (preferred original stills version), spoken commercial audio
- Public dump: https://github.com/ford442/weeks_on_fire/issues/32

## How to add ideas

Drop a comment on #32 **or** add an entry under **Idea log** (newest first):

```
**Type:** song / visual / pipeline / lore
**Idea:** ...
**Why it might be fun:** ...
```

Or just dump the thought — anything is fine.
