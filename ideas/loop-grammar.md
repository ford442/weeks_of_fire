# WoF loop grammar

Shared rules for **seamless loop tiles** — 2–8s cycles that can sit as a bumper, as
EyeWash Station wallpaper behind a card, or as a repeating in-between under a Minimax bed.
Not a new short. Not a cutaway. A tile.

**Farm:** [#22](https://github.com/ford442/weeks_on_fire/issues/22)
**Catalog:** [`ideas/short-packet-farm.md`](short-packet-farm.md) · **Boards:** [`prompts/short-packet-farm-segments.md`](../prompts/short-packet-farm-segments.md)
**Date:** 2026-09-09

A loop is a first-class deliverable. It is not the leftover from a cutaway that did not
get finished.

## The four rules

### 1. Last frame = first frame

Pose, light, and object position all return. Not "roughly returns" — returns. Write the
loop by writing the **rest pose** first, then the departure, then the way back to the
same rest pose. If you cannot describe the rest pose in one sentence, the tile is not a
tile yet.

Three things that break a loop and are easy to miss:

- **Light drift.** A practical that warms or cools across the cycle. Lock the lamp.
- **Accumulation.** Paper stacking up, water level rising, dust settling. Whatever the
  object handles must be handed back.
- **Camera.** No push, no drift, no breathing handheld. Locked, or a slow orbit whose
  period divides the cycle exactly.

### 2. One moving system only

Marbles, or the drip, or the stamp, or the orbit, or the bag. **One.** Everything else
in frame is furniture and stays furniture. Two systems make a scene; a scene is not a
tile, it is a bridge, and the bridge shelf starts at 45s.

Borrowed from the Marble rule and it holds here: *dancers hop, magnets orbit.* If a
second object starts doing a job, kill the take.

### 3. Hold a rest pose

Every tile parks for a beat — roughly 15–20% of the cycle — in a still frame with the
object at home. That rest is what clip_stacker and the timed slideshow land on. It is
also where a cut in or out is invisible.

The rest pose is the tile's identity. Someone should be able to recognise the packet from
the rest frame alone, with nothing moving.

### 4. Silent picture

No score, no room tone bed, no laugh track on a tile. The only sound a tile may carry is
**one diegetic click, tick, crease, or latch that belongs to the object** and lands on
the same frame every cycle. That single sound is what makes the loop feel intentional
instead of stuck.

If a tile needs music, it is being used as an in-between and the bed goes on top in the
stacker. The picture still ships silent.

## Cycle lengths

| Length | Reads as | Good for |
|--------|----------|----------|
| 2–3s | A tic. Almost subliminal. | Behind a card, under a title, corner of a monitor wall |
| 4–5s | One complete gesture | Bumper, EyeWash wallpaper, standalone tile |
| 6–8s | A short routine with a wrong turn in it | The upper limit. Past 8s the eye starts looking for a story |

Anything longer is a bridge, not a tile.

## Job vocabulary

The eight motions that loop cleanly in this series. Pick one per tile.

| Job | Reads as | Fails as |
|-----|----------|----------|
| **Orbit** | One body circles a fixed point and returns to the same clock position | A body that wanders; a moon with a planet |
| **Tick-tock** | Two-position swing, equal dwell each side | A pendulum losing amplitude |
| **Drip** | Forms, falls, is absorbed, re-forms at the same spot | A puddle that grows |
| **Stamp** | Lift, strike, lift, back to the same height | A stamp that leaves a darker mark each pass |
| **Bag-lift** | An object is carried a fixed distance and handed back to the start | A conveyor that runs one way forever |
| **Cabinet-slide** | Open, reveal, close, latch | A drawer that ends open |
| **Cube-at-chest** | Quarter-turn per tick, four ticks, home | A tumble; a spin with no detents |
| **Form-duplicate** | One becomes two becomes one | Two that stay two |

## Materials

Loops read best on materials that hold a highlight in a locked frame: **porcelain,
marble insert, honey-oak, brass, wet enamel (ground only), geometric white panels, short
honeycomb-guard props, pale pink lamp-eyes.** Wet things and matte things next to each
other. No chrome-everything, no glass-everything.

Wet enamel obeys the field grammar: it runs on the **ground**, between and below, never
climbing an object or a wall. See [`ideas/wildflower-paint-rivulets.md`](wildflower-paint-rivulets.md).

## Writing the prompt pair

Two prompts per tile, always.

1. **Rest-pose still.** Full Imagine order — subject → bodies → job → 3–4 supporting
   figures → room → light → lens/grade. This is the frame the loop returns to.
2. **Motion prompt.** Short. Names the one system, the cycle length, the return, and the
   single sound. Explicitly forbids camera movement and accumulation.

The motion prompt should read like a machine spec, not like coverage:

> *"5-second seamless loop. [One system] does [one job] once and returns to the exact
> opening position. Nothing else in frame moves. Camera locked, no push. No level rises,
> no stack grows, no light changes. Ends on the opening frame."*

## Where tiles go

- **EyeWash Station wallpaper** — behind the card, behind the schedule, behind a hold.
  The station never comments on it (`ideas/eyewash-station.md`: slide, never comment).
- **Bumpers** — between packets on the Suggestions schedule.
- **In-betweens** — repeated under a Minimax bed as an animation bridge's connective
  tissue, when the bridge itself does not need new picture.

A tile never carries a story beat. If it is carrying a beat, promote it to a joke
interrupt and give it a punch.
